# Карточный бизнес: таблица, ассистент и скрипт

> Работаете на общем стенде через VS Code в браузере? База и Metabase здесь
> не нужны — только Excel/Google Таблицы и ассистент. Общие шаги стенда —
> в [`../_STAND.md`](../_STAND.md).

**Управленческий вопрос.** Карты выдаём, а покупок в первый месяц нет. Где именно
теряется активация и что делать с этим каналом?

Показываем путь целиком: необработанная выгрузка → просим ассистента написать скрипт →
выполняем скрипт → получаем сводную и диаграмму прямо в таблице.

## Что в папке

| Файл | Зачем |
|---|---|
| `2.5.1_выгрузка_для_google.csv` | выгрузка для Google Таблиц (импорт файлом) |
| `2.5.2_выгрузка_для_excel.xlsx` | та же выгрузка для Excel, лист «Выгрузка» |
| `2.5.3_промпт_google_таблицы.txt` | промпт ассистенту, если работаете в Google Таблицах |
| `2.5.4_промпт_excel_vba.txt` | промпт ассистенту, если работаете в Excel |
| `2.5.5_разбор_ответа_ассистента.md` | что ассистент сделал не так и как это заметить |
| `2.5.6_эталон_google_apps_script.gs` | рабочий скрипт для Google Таблиц |
| `2.5.7_эталон_excel_vba.bas` | тот же алгоритм макросом для Excel |

Промпта два, потому что скрипты разные: Apps Script и VBA — разные языки
и разные ловушки. Общая часть — описание данных и их дефектов — совпадает
дословно, различаются требования к коду.

## Что не так с выгрузкой

Всё как в жизни: повторы строк после склейки файлов, даты в двух форматах и «н/д»,
суммы то с пробелом-разделителем, то с запятой, а канал оформления записан
тринадцатью разными способами — «Отделение», «отделение», «ОТДЕЛЕНИЕ », «Офис банка»,
«МП», «Партнер»… Пока это не приведено к четырём значениям, любая группировка по
каналу даёт бессмысленную таблицу на тринадцать строк.

## Как провести

Путь один и тот же, различаются два шага — куда вставлять данные и куда вставлять
код. Выберите свой сценарий и идите по нему целиком, не смешивая.

### Сценарий A. Google Таблицы

**1. Импорт.** Google Таблицы → «Файл → Импортировать → Загрузить» →
`2.5.1_выгрузка_для_google.csv`, разделитель — точка с запятой. Лист назвать
«Выгрузка». Покажите вкладку: 2472 строки, канал написан вразнобой.

**2. Запрос к ассистенту.** Вставьте текст из `2.5.3_промпт_google_таблицы.txt`.
Ассистент выдаёт скрипт Apps Script за полминуты.

**3. Приёмка кода — главная часть.** Прежде чем запускать, проверьте скрипт по
списку из `2.5.5_разбор_ответа_ассистента.md`: там ровно те ошибки, которые ассистент
делает на этой задаче. Найти их в чужом коде за минуту — это и есть навык.

**4. Выполнение.** «Расширения → Apps Script», вставить проверенный скрипт,
запустить `obrabotatVygruzku`. Если времени мало — вставляйте сразу
`2.5.6_эталон_google_apps_script.gs`, он проверен.

### Сценарий Б. Excel

**1. Открыть файл.** Скачайте `2.5.2_выгрузка_для_excel.xlsx` и откройте
в Excel — лист «Выгрузка» уже назван правильно. Сохраните книгу как
`.xlsm` (книга с поддержкой макросов), иначе код в ней не сохранится.

**2. Запрос к ассистенту.** Вставьте текст из `2.5.4_промпт_excel_vba.txt` —
он просит макрос VBA и предупреждает ассистента про разбор дат и сумм
на разных региональных настройках.

**3. Приёмка кода.** Тот же список из `2.5.5_разбор_ответа_ассистента.md`: ошибки
у ассистента одинаковые на обоих языках, отличается только запись.

**4. Выполнение.** Alt+F11 → «Insert → Module», вставить проверенный код,
F5 или «Run → Run Sub», процедура `ProcessIssuedCards`. Готовый макрос —
`2.5.7_эталон_excel_vba.bas`.

**5. Результат (одинаковый в обоих сценариях).** На листе «Выгрузка» — 2400 строк,
чистые даты и числа, новый столбец активации. На листе «Активация» — две сводные
таблицы и диаграмма.

активацию вообще», а про один канал и то, что происходит с клиентом сразу после
оформления карты.

## Проверка

Логика эталонного скрипта прогоняется на той же выгрузке вне таблиц:

```bash
node tools/check_apps_script.js
```

Скрипт сверяет число строк после чистки, разбор дат и сумм, приведение каналов и
все восемь чисел из таблиц выше.

## Домашнее задание

Пройдите тот же путь на своих данных: выгрузка → промпт → скрипт → сводная.
Достаточно одной таблицы, которую вы и так регулярно приводите в порядок вручную.

Если своих данных под рукой нет или их нельзя выносить наружу — возьмите
выгрузку из этой папки и пройдите путь на ней.

> **Какие данные куда.** Публичный ассистент видит всё, что вы ему отправили.
> Данные, которые нельзя выносить из контура банка — клиентские, персональные,
> внутренние выгрузки, — обрабатывайте ассистентом в закрытом контуре банка,
> а не публичным. Правило простое: если выгрузку нельзя приложить к письму
> наружу, её нельзя вставить и в публичный чат с моделью.
>
> Отдельный приём для промежуточного случая: сам скрипт можно получить
> и на обезличенном фрагменте — двадцать строк с теми же заголовками
> и типами данных, — а запускать его уже на полной таблице у себя.
