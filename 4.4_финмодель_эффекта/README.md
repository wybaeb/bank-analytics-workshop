# 4.4 · Финансовая модель эффекта

Тетрадь считает эффект проекта на кейсе накопительного счёта: множители,
которые есть в выгрузке, — из данных; остальные — допущения с диапазонами.
Дальше — поток эффекта по месяцам с накоплением когорт, окупаемость, NPV,
проверка чувствительности (диаграмма «торнадо»), три сценария и текст для
слайда «Эффект для бизнеса».

| Файл | Что это |
|---|---|
| `4.4.1_финмодель_эффекта.ipynb` | тетрадь с расчётом и графиками; выполнена, выводы встроены |
| `сделать_тетрадь.py` | генератор тетради (служебный) |

Данные: `../data/product/savings_monthly.csv` — та же выгрузка, что в кейсе
страницы анализа. Формулы расчёта повторяют тренажёр «Финансовая модель
эффекта» из материалов курса; теория — страница «Финансовая модель проекта».

Чтобы перенести на свой проект: заменить раздел 1 расчётом своих множителей
из выгрузки, в разделе 2 записать допущения с диапазонами, остальное
выполняется без изменений.
