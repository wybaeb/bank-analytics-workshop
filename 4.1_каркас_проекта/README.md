# 4.1 · Каркас проекта

Шаблоны проектной работы. Заполняются по разделам; страница с разбором
каждого элемента — «Каркас проекта: от проблемы до эффекта» в материалах
курса.

| Файл | Что это |
|---|---|
| `4.1.1_шаблон_презентации_проекта.md` | презентация проекта из 5–7 слайдов по каркасу проблема → метрика → данные → инструмент → анализ → вывод → эффект, с чек-листом |
| `4.1.2_шаблон_письма_команде.md` | письмо команде на одну страницу: что меняем, по какому показателю судим, какие данные начинаем собирать, первое действие, когда пересматриваем; с примером |
| `4.1.3_примеры_каркасов.md` | три заполненных каркаса на кейсах репозитория: карточный бизнес, накопительный счёт, портфель операций |

Расчёт эффекта для слайда «Эффект для бизнеса» — тренажёр «Финансовая
модель эффекта» в материалах курса или тетрадь `4.4_финмодель_эффекта`.
