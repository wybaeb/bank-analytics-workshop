# Презентация проекта — шаблон (5–7 слайдов)

Каркас: **проблема → метрика → данные → инструмент → анализ → вывод → эффект**.
Один слайд на элемент; порядок изложения — от вывода к основаниям.
Заполняется по разделам и переносится в любой редактор презентаций.

## Слайд 1 · Проблема
- Объект изменений (продукт / процесс / бизнес-инициатива): …
- Показатель, текущее значение, период измерения: …
- Источник значения (выгрузка, витрина, отчёт): …
- Целевое значение и срок: …
- Кто принимает решение об изменении: …

## Слайд 2 · Метрики
- Метрика результата (запаздывающая), единица, период: …
- Драйверы (опережающие), на которые направлено изменение: …
- Контрольная метрика, которая не должна ухудшиться: …
- Фрагмент дерева: стрелки от драйверов к результату (снимок из тренажёра «Дерево метрик» — по желанию).

## Слайд 3 · Данные
| Метрика | Собирается сейчас | Путь получения | Первое проверенное значение через |
|---|---|---|---|
| … | регулярно / по запросу / нет | витрина / выгрузка по договору / новый сбор | дни / недели / месяцы |

- Чего нет и что делается до получения (допущение помечено): …

## Слайд 4 · Инструмент
- Чем выполняется расчёт: таблица / мини-инструмент / BI / тетрадь Python: …
- Кто повторяет расчёт на следующей выгрузке: …
- Одна строка обоснования: …

## Слайд 5 · Анализ и вывод
- Что сделано с данными (очистка, свёртка, расчёт, проверка): …
- **Факт:** …
- **Интерпретация:** …
- **Гипотеза:** …

## Слайд 6 · Эффект для бизнеса
Текст из тренажёра «Финансовая модель эффекта»:
- Формула: Δ × V × P = … в месяц
- Выход на уровень, срок сохранения, горизонт: …
- Затраты единовременные / ежемесячные: …
- Доход за первый год, окупаемость, NPV за горизонт: …
- Допущения и результат проверки чувствительности (какое меняет вывод): …

## Слайд 7 · Следующий шаг
- Первое действие: …
- Срок и ответственный: …
- Дата первой сверки метрики и условие отмены решения: …

## Чек-лист перед показом
- [ ] Проблема содержит число, источник и целевой уровень.
- [ ] В дереве есть и результат, и драйверы; у каждой метрики — единица и период.
- [ ] По каждой метрике понятно, откуда данные, и отмечено, чего нет.
- [ ] Эффект посчитан только на данных, которые собираются или будут собираться; допущения помечены.
- [ ] Названо допущение, на котором вывод меняется, и его пессимистичное значение.
- [ ] Слайдов 5–7, каркас соблюдён; слайд «Эффект» читается без ведущего.
